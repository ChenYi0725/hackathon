# 空白書表修正（DDD-08）

題目文字中的因素名稱和兩側值被分行時，原解析器沒有對應任何欄位；即使有已確認的計算輸入，原填結果為空也不提供可採用的建議。整理書表另遺漏已抽取的等級。

本次支援同一頁內獨立因素名稱後緊接兩個獨立值、可選的明示百分比修正率。保留原始換行引用、未確認狀態，不跨頁或跨說明段落拼值；多比較標的、角色不明或不完整列仍保留待確認。

已有確認輸入且能用既有公式求值時，空白結果會顯示重算建議，使用既有「採用建議」流程保存。未確認或缺少輸入時不提供猜測值，不改公式。套用後仍需重新確認；revision 衝突保護不變。

HTML 整理書表顯示原值及等級，並列原填數字和程式重算供核對；空值顯示待補，解析限制一併輸出。匯出不修改案件、確認或 audit。審查報告及整理書表可用瀏覽器列印為 PDF。

舊案件不會自動重新 OCR；需重新匯入題目或補正欄位才能得到新解析結果。多比較標的完整自動填表仍未實作，本修正不宣稱支援三標的題目。AWS 發布沿用既有 Knowledge Base 與 PDF 文字層加速，不將其混入本 PR。

驗證：Python 1,210 passed、7 skipped；Chrome Playwright 11 passed。使用合成資料將 report/forms 各列印成 2 頁 PDF，逐頁渲染確認等級、2.5% 原填率及 102.0 重算值可見，沒有整頁空白。未使用使用者的實際題目案件作驗收。
