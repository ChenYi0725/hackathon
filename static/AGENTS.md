# 操作介面開發範圍

先讀根目錄 [AGENTS.md](../AGENTS.md)及 [TODO](../docs/TODO.md)。本目錄主要負責 DDD-06，HTTP 契約由 application／interfaces 協調。

- 使用 API 提供的比較標的 ID、revision、計算結果與引用；不要依畫面欄位順序推定標的身分。
- 呈現草稿、待確認與已確認狀態，套用 AI 草稿保留人工備註；不得把模型回覆直接顯示成已核准結論。
- JS 只處理互動與顯示，不實作估價公式或以畫面格式化值反寫計算結果。
- PDF 下載使用後端產製結果，保留產製錯誤提示；涉及流程的修改更新 `e2e/` 並驗證桌面與窄螢幕操作。
